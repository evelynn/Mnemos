SQL query — validate & authorise (read-only)

The platform never connects to a production DB itself (spec §2.5/§2.8). This form checks and authorises a SELECT: SQLGlot blocks anything that mutates state, an oversized LIMIT is clamped, per-DB policy (sensitive tables, AWR consent, maintenance window) is enforced, and the request is written to the audit log. It returns the rewritten SQL for the analyzer to run; the masked rows then show up in the Sample viewer above once the analyzer reports them back.
