Diffs (Gate B)

Every submission runs through a multi-pass review (rules → contracts → data_access → impact → second_opinion → validator). Critical findings block approval. To clear a block an admin first requests a break-glass grant (which re-runs the pipeline and is refused while still blocked), then a different user approves with the returned token (initiator ≠ approver, 15-min TTL, single use). Philosophy: docs/ultrareview.md.
