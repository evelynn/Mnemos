SSO / OIDC

OIDC is configured via environment variables on the platform container so credentials never land in the database. Toggle a restart after changing .env.

Runtime status

Click refresh.

Required env vars

OIDC_ISSUER=https://login.example.com/auth/realms/corp
OIDC_CLIENT_ID=mnemos
OIDC_CLIENT_SECRET=...
OIDC_REDIRECT_URI=https://mnemos.example.com/api/v1/auth/oidc/callback
OIDC_SCOPES="openid email profile"

Callback route: /api/v1/auth/oidc/callback. Login trigger: /api/v1/auth/oidc/login.
