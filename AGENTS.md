# AGENTS.md — Mnemos

**Read `CLAUDE.md` (repo root) first — it is the authoritative project charter.**

One-line purpose: Mnemos is an **AI-assist tool for analyzing large source code** (recursive
graph analysis + grounding + bitemporal knowledge graph + MCP re-query + clear tables). It is
**not** a generic SaaS/chatbot/admin product. Every change must serve AI-assisted source
analysis; if it doesn't, it is out of scope — stop and confirm with the user.

The 5 pillars, the hard anti-drift guardrails, the known Phase-2 gaps, and the stack map are all
in `CLAUDE.md`. Do not duplicate them here; keep `CLAUDE.md` as the single source of truth.
